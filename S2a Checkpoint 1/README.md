# my web app idea

problem: not enough people want to grow their own food. too difficult? not enough time? don't know where to start?

user will enter a name for there plot, e.g. back garden

they can pick the size of there plot, e.g. 2x2 metres

this will then generate a 2.5d or 3d model grid of land on the user screen which they can mould into whatever shape there garden is.

from then they can type in some things they would like to grow or have interest in growing in the future.

they can drag as many plants in as the plot allows for and once all are planted it will generate the type of care it will take to run this garden. how often a user will water, sow etc.

it will give tips for where to position, what time of year to grow. when to check.

by the end the user will be able to view there garden from start to finish, and how much food they should have by the end of there 'harvest' the rough cost, the hours needed to put in and the chance of success (using an llm to read the users input data to generate this end report and shopping list)

entire model will be movable (can position depending on where sun hits garden?) then from this a 'receipt' like report is generated and can be downloaded.

apis needed: 

3d modeling? p5?
weather
plants
llm
create own? purely use llm to generate data?

UI ideas consist of seeds being in a drawer component made in p5 with each seed/plant having its own category, from here a hover state will reveal information about the plant itself
